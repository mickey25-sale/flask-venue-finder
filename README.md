Flask Campus Venues

A beginner-friendly Flask web application designed to help students at Alupe University find campus venues and check their availability.

Features

- View campus venues and their availability status
- Interactive map using Leaflet.js
- Search for venues
- Filter venues by availability
- Retrieve venue information through a Flask API
- Read venue data from a published Google Sheets CSV

Technologies Used

- Python
- Flask
- HTML, CSS and JavaScript
- Leaflet.js
- Google Sheets CSV

Running Locally

1. Clone this repository:
   
   git clone https://github.com/mickey25-sale/flask-venue-finder.git

2. Enter the project folder:
   
   cd flask-campus-venues

3. Create and activate a virtual environment.

4. Install dependencies:
   
   pip install -r requirements.txt

5. Start the Flask application:
   
   python app.py

6. Open the local address shown in your terminal in your browser.
